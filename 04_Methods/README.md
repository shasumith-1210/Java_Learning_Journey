# 📘 Chapter 4 — Methods

> Write cleaner, reusable and modular Java programs.

---

## 📖 Overview

Methods are one of the most important features of Java. They allow large programs to be divided into reusable, maintainable, and organized blocks of code.

This chapter introduces method creation, parameters, return values, recursion, overloading, variable arguments, and real-world applications.
