# 📘 Chapter 2 — Decision Making

> Learn how programs make decisions.

---

## 📖 Overview

Conditionals allow programs to execute different blocks of code based on certain conditions. This chapter introduces the `if`, `if-else`, `else-if`, nested `if`, `switch`, and ternary operator.

---

## 🎯 Learning Objectives

- Write conditional statements
- Compare values effectively
- Handle multiple decision paths
- Use switch-case statements
- Write concise conditions using the ternary operator
