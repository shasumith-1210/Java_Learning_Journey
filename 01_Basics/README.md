# 📘 Chapter 1 — Java Basics

> Build a strong foundation before moving to problem-solving.

---

## 📖 Overview

This chapter introduces the fundamental building blocks of Java programming. It covers program structure, variables, data types, operators, user input, type conversion, and output formatting.

Every Java developer starts here.

---

## 🎯 Learning Objectives

After completing this chapter, you'll be able to:

- Understand the structure of a Java program
- Declare and use variables
- Work with Java's primitive data types
- Accept user input using `Scanner`
- Perform arithmetic and logical operations
- Convert between different data types safely
