# 📖 About

Welcome to my **Java Learning Journey**!

This repository documents my journey of learning Java—from writing my very first **"Hello World"** program to building complete Java applications.

Rather than simply collecting code, this repository is organized topic-wise with well-structured examples, practice programs, mini projects, and Data Structures & Algorithms. Every folder represents a milestone in my learning and serves as a quick reference for future revision.

As I continue learning, I'll regularly add new programs, improve existing solutions, and build projects that strengthen my understanding of Java and software development.
